# Premium Scientific Calculator

A beautifully designed, fully functional scientific calculator built with HTML, CSS, and JavaScript. 

It features a modern glassmorphism aesthetic with responsive animations, a dynamic dark-mode color palette, and robust mathematical processing capabilities. 

## Features
- **Advanced Trigonometry:** Accurate calculation of `sin`, `cos`, and `tan` using degrees.
- **Scientific Operations:** Support for factorials (`!`), logarithms (`log` base 10, `ln` base e), exponentials (`x^y`), and square roots (`√`).
- **Mathematical Constants:** Quick access to Pi (`π`) and Euler's number (`e`).
- **Smart Interface:** Auto-closing parentheses and automatic font-scaling to prevent overflowing text for large results.
- **Keyboard Support:** Fully mapped keyboard inputs for rapid typing and calculation.

## How to Use the Calculator

You can use the calculator directly in your web browser! No installation or coding required. 

*(Note: If you have set up GitHub Pages, you can place your live link here: `https://amankr8525.github.io/Scientific-Calculator/`)*

### Local Execution
If you want to run the code locally on your own machine:
1. Clone this repository.
2. Simply double-click the `index.html` file to open it in any modern web browser.
3. Alternatively, you can run the included Python Flask server by running `pip install -r requirements.txt` and then `python app.py`.
